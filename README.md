# SevenScale Digital — Bongabon Resort Directory

This package contains the complete source code for the SevenScale Digital resort website.

## Files

- `index.html` — page structure and website content
- `styles.css` — blue visual design and responsive layouts
- `app.js` — resort data, filters, dates, and booking-request interactions

## Run locally

Open `index.html` in a modern web browser. For the most reliable behavior, serve the folder with any static web server.

## Publish on your own domain

Upload all four files to the public directory of a static web host. Point your custom domain's DNS records to that hosting provider using its instructions.

## Important prototype limitation

Booking requests are currently saved only in the visitor's browser. A database, resort-owner portal, email service, or booking-platform integration is required before requests can be delivered automatically to resorts. Rates and availability must be confirmed with each property.

## External content

Some resort photos and directory links load from public third-party URLs. These may change or become unavailable. Replace them with authorized property images before using the website as a production booking platform.
